## Project

`junior-skill` is a Claude Code skill: it explains recent work to a junior developer as a learning-oriented walkthrough (concept, reasoning, further reading) rather than a changelog.

## Workflow

- Branches: `main` (stable), `dev` (active development). Work on `dev` or feature branches off `dev`; merge to `main` via PR.
- Remote: https://github.com/stefanwuthrich/junior-skill (public) — never commit secrets.
